# Travaux pratiques de Programmation Orientée Objet en Java

Dépôt regroupant mes TP du cours de **Programmation Orientée Objet (POO)** en Java, en Licence 3 Génie Logiciel et Système d'Information (L3 GLSI) à l'**École Supérieure Polytechnique (ESP)** de l'**Université Cheikh Anta Diop (UCAD)** de Dakar, année 2026-2027. Cours dispensé par Dr Guy MBATCHOU.

## Liste des TP

| Dossier | Thème | Description |
|---|---|---|
| [TP1.2](TP1.2/) | Installation des IDE et réalisation d'un micro-projet | Somme des entiers de 1 à n, exécutée et déboguée pas à pas dans l'IDE. |
| [TP1.4](TP1.4/) | Construction de la chaîne d'outils d'un projet | Projet Maven avec JavaFX (fenêtre créée sous Scene Builder) et connexion à MySQL via JDBC. |
| [TP2.1](TP2.1/) | Gestion des étudiants | Classes `Etudiant` et `Promotion` : ajout, recherche par matricule, moyenne générale. |
| [TP2.2](TP2.2/) | Gestion de la hiérarchie de formes et d'employés | Paie d'employés (Manager, Vendeur, Stagiaire, Directeur) et aire de formes géométriques. |
| [Exercices/exo28](Exercices/exo28/) | Conception de la hiérarchie d'un système | Biens immobiliers (Appartement, Villa) dont le calcul des charges est redéfini. |

## Prérequis

- JDK 25
- Maven 3.10 (pour TP1.2 et TP1.4)
- MySQL (pour la partie base de données de TP1.4)

## Éditeur

Les TP ont été réalisés avec **IntelliJ IDEA**.
