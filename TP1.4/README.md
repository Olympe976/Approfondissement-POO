# TP 1.4 : Construction de la chaîne d'outils d'un projet

Séquence 1, Objectif 1.4 : Installer d'autres outils indispensables.

## Énoncé

1. Installer Maven et vérifier la version.
2. Installer Git et vérifier la version.
3. Créer un projet Maven incluant JavaFX et une connexion d'accès à une base de données.
4. Installer Scene Builder et l'ouvrir.
5. Créer une fenêtre vide enregistrée dans `vue.fxml`.
6. Initialiser un dépôt Git.
7. Ajouter un `.gitignore`.
8. Faire un premier commit.
9. Publier le projet sur un dépôt distant.
10. Inviter ses camarades.

## Contenu

- Projet Maven `sn.ucad.esp.glsi:tp14`, Java 25, créé avec l'archétype JavaFX FXML
- JavaFX 25.0.5 (`javafx-controls`, `javafx-fxml`) et `javafx-maven-plugin` 0.0.8
- Fenêtre vide `vue.fxml` créée avec Scene Builder (`src/main/resources/sn/ucad/esp/glsi/`)
- Connexion à MySQL (base `tp13`, table `information`, utilisateur `esp`) avec `mysql-connector-j` 26.10.0, dans la classe `Test_MySQL`
